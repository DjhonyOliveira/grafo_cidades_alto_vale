# Aplicação Representando a estrutura de dados em grafos com base nas cidades do alto vale do itajaí

Este projeto tem por finalidade demonstrar a utilização de uma estrutura de dados muito utilizada, os grafos. A aplicação tem como base a ligação das cidades do alto vale do itajai por meio de um grafo. A aplicação tem como stacks principais o JS para montar o frontEnd e o PHP para executar a lógica do grafo.

---

## Requisitos

* PHP 8.0 ou superior
* Acesso ao terminal/linha de comando.

---

## Instruções de execução

Realize o clone deste repositório utilizando o comando a baixo:

```bash
git clone https://github.com/DjhonyOliveira/grafo_cidades_alto_vale.git
```

Posteriormente, navegue até a raiz do projeto e execute um servidor local utilizando o proprio php com o seguinte comando:

```bash
php -S 0.0.0.0:8000
```

Endereço IP e porta utilizada deve ser validado conforme disponivel no ambiente a ser executado
